# Report Writing 

Report Writing Occurs in the bug bounty so that the organisation that contains the bug bounty program can reproduce the bug that impacted their security and award the money or reward according to the vulnerability

## Structure of the Report Writing 

### Title 

It contains the short information about the vulnerability that exist in the target applications

### Summary 

Briefly information about the vulnerability in 2-3 sentences and contains the impact and affected component

### Vulnerability Details 

- Explain the type of vulnerability (XSS, SQLi, IDOR, or other vulnerability)
- Including the attack surface informations (endpoint, parameter, feature)
- Reference OWASP category if relevant

### Step to reproduce 

Step wise procedure to make the vulnerability so that triage can also replicate it 

### Proof of Concepts (PoC)

Contains the video or screenshot of explanations to depicts the steps and it is the main part for the bug bounty because the PoC makes the triage to replicate it easier for the verification of the vulnerability 

### Impact 

It describe the losses or the beneficial of the attacker due to the vulnerability that is found

### Remediation 

Suggest the remediation to fix the vulnerability and stop the attacker using the same vulnerability
